## 2. Description of Service

AuraDrop is a peer-to-peer (P2P), local-first software utility that facilitates high-speed direct file transfers and local communication across devices connected to the same Local Area Network (LAN) or Wi-Fi network.

AuraDrop does not provide cloud hosting, file storage, relay infrastructure, or remote file indexing. All file transfers occur directly between the sender and receiver devices on your private network.
