Features

Built for speed
and simplicity.

Every feature ships to make sharing feel effortless.

Nearby Discovery

Automatically finds AuraDrop devices on your local network using LAN mDNS scanning and a cloud signaling fallback — no setup required.

Secure Pairing

One-time session tokens, single-use upload authorization, and device pairing with explicit consent before any data moves.

High-Speed LAN Transfer

Streams files directly between devices over your LAN. SHA-256 integrity verification ensures every byte arrives exactly as sent.

Cross-Platform

Share between Android and Windows seamlessly. A web receiver lets any browser-capable device receive files on the same network.

Peer Messaging

Send text messages directly to connected devices. Chat history is stored locally and never leaves your network.

Resume & Cancel

Pause, resume, and cancel transfers mid-stream. Incomplete files are cleaned up automatically — no orphaned partials left behind.

How it works

Three steps,
then it's done.

AuraDrop handles the network complexity so you don't have to.

01

Discover nearby devices

Open AuraDrop on any Android or Windows device on the same Wi-Fi. Nearby devices appear automatically within seconds — no IP addresses or QR codes needed on a shared network.

02

Connect and approve

Select a device and initiate a connection. The receiving side sees an approval prompt showing the sender's name, device, and the file details before anything is transferred.

03

Transfer at full LAN speed

Files stream directly between devices with real-time progress, speed, and ETA. A SHA-256 checksum is verified on arrival — your file is only accepted when every byte matches exactly.

Security & Privacy

Your data stays
on your network.

AuraDrop is designed to minimize attack surface and require explicit consent at every step.

Implemented

Single-use upload tokens

Every file transfer requires a server-generated one-time token issued to the sender. Tokens expire after 60 seconds and are invalidated the moment the upload stream begins — replaying a token returns a 403.

Implemented

SHA-256 integrity verification

The sender declares a SHA-256 checksum before sending. The receiver computes the hash incrementally while streaming. If the final hash does not match, the file is deleted and the transfer is rejected.

Implemented

Explicit pairing consent

Pairing requires a server-issued code that the target device must confirm. Client-supplied device IDs are never treated as proof of identity. Revocation and expiry are enforced at the database level.

Implemented

Local-first transfer path

When both devices are on the same LAN, files transfer directly between them over HTTP — they never route through our signaling servers. The cloud path is used only for device discovery and signaling.

AuraDrop does not currently provide transport-layer encryption (TLS) on local HTTP transfers. Files are transferred in cleartext over your LAN. On a trusted private network this is acceptable; on untrusted or public Wi-Fi, avoid transferring sensitive files.
