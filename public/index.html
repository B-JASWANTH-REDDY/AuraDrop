Engine Features

Engineered for pure velocity.

AuraDrop bypasses public cloud intermediaries and streams data directly over high-speed local network sockets, Wi-Fi 6/7, and WebRTC data channels.

01 / SPEED

100+ MB/s LAN Streaming

Direct TCP and HTTP chunked streams transfer raw bytes at the physical throughput limit of your local router without uploading to any external server.

02 / UI

Desktop & Mobile Dynamic Island

A native floating pill for Windows desktop mirroring Android’s dynamic island. Track live transfer speeds, ETAs, and connected peers unobtrusively.

03 / SECURITY

Fail-Closed Authentication

Single-use cryptographic upload tokens expire in 60 seconds and invalidate immediately upon transfer initiation. Spoofed device IDs receive immediate 403s.

04 / INTEGRITY

SHA-256 Byte Verification

Receivers calculate streaming SHA-256 checksums incrementally. Files with mismatched hashes or truncated bytes are automatically rejected.

05 / PRIVACY

Zero-Cloud Local First

Devices on the same network discover each other via UDP multicast announcements. No account, no signup, and zero internet upload required.

06 / MESSAGING

Encrypted P2P Chat

Send instant messages, code snippets, and clipboard links across devices securely with zero server retention or third-party storage.

Protocol Flow

How AuraDrop transfers work.

Four deterministic steps guarantee private, zero-latency transfers across any combination of operating systems.

1

LAN Discovery

Devices announce presence via UDP multicast and local WebSocket heartbeats. Peer IP addresses and capabilities are resolved instantly.

2

Token Handshake

Sender requests a single-use authorization token. The receiver verifies sender identity and generates an ephemeral session key.

3

Direct Streaming

Bytes stream directly over high-throughput local sockets or WebRTC data channels, utilizing 100% of available LAN bandwidth.

4

Checksum Audit

The receiver verifies exact byte length and SHA-256 hash before flushing the file to disk or the Android MediaStore gallery.

Enterprise & Security

Zero-trust local compliance.

Designed for teams and organizations handling sensitive source code, confidential media, and regulated data.

SEC / 01

Air-Gapped Operation

Operates seamlessly on closed local-area networks and air-gapped environments without requiring an active internet connection.

SEC / 02

Zero Data Retention

Signaling servers never inspect, stage, or store file bytes. Transfers occur device-to-device over direct peer sockets.

SEC / 03

Single-Use Tokens

Every upload generates a 60-second cryptographically random single-use token that self-destructs the moment the transfer begins.
